# Casos de uso (fuente original)

Acá van los `.md` de los casos de uso tal como los entrega negocio (ej.
`UC-PRE-3_5-Seleccion_y_Registro_de_Etapas.md`), y cualquier `contrato-CU-XX.md`
donde se documenten las ambigüedades/decisiones encontradas al derivar el
`.openapi.yaml` de ese CU.

Un archivo por CU, con el mismo nombre que ya se cita en los comentarios del
`.openapi.yaml` correspondiente (`back/src/main/resources/openapi/<dominio>/CU-XX.openapi.yaml`),
para que sea fácil ubicarlo a partir de esa referencia.

Estos documentos son la fuente de verdad de negocio, no se generan ni se
derivan de otra cosa — no se editan salvo que negocio entregue una versión
nueva.
